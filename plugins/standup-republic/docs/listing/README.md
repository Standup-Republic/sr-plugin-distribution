Die Listing-Copy beschreibt ausschließlich Fähigkeiten, die der jeweilige

## Creatives

Die rootnahen Marketplace-Assets liegen unter `../../assets/`. Herkunft,
Dimensionen und SHA-256-Hashes stehen in `../../assets/manifest.json`. Die
wiederverwendbare vollständige Brand-Ressource für interne Dokumente und
weitere freigegebene Anwendungen liegt unter
`../../skills/sr-plugin/assets/brand/`.
